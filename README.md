# projecten

Alle eigen projecten van Guy, per domein. De mappen hier komen overeen met de
mappen op de werkmachines, zodat een pad hetzelfde betekent op GitHub en lokaal:

```
projecten/thuis/ha-config      ~/projecten/thuis/ha-config
projecten/politiek/...         ~/projecten/politiek/...
```

## Domeinen

- **thuis** - huis, Home Assistant, alles rond het gezin en de praktijk
- **politiek** - het raadswerk
- **werk** - nog leeg

## Wat hier niet in staat

Grote data blijft buiten git: audio, video, modellen, archieven en Python-venvs.
Die staan op de NAS of worden per machine opnieuw opgebouwd. Elk project legt in
zijn eigen README uit wat het nodig heeft en hoe je het opzet.

Deze repo is prive en blijft dat.
